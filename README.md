# EtudeAnalytics-support

Public support site for the EtudeAnalytics iOS app (App Store Support URL + Privacy Policy URL).

## Deploy with GitHub Pages

### Option A (recommended): Pages from `main` / root
1. Push this repo to GitHub.
2. GitHub repo **Settings → Pages**
3. **Build and deployment**: Deploy from a branch
4. Branch: `main`  / Folder: `/ (root)`
5. Save → wait for Pages to publish.

Your URLs will look like:
- Support URL: `https://<your-github-username>.github.io/EtudeAnalytics-support/`
- Privacy Policy URL: `https://<your-github-username>.github.io/EtudeAnalytics-support/privacy.html`

## Customize
Replace these placeholders in the HTML files:
- `SUPPORT_EMAIL_HERE`
- `APP_VERSION_HERE`
- `LAST_UPDATED_DATE_HERE`

## Files
- `index.html` — Support page (EN/JA)
- `privacy.html` — Privacy Policy (EN/JA)
- `terms.html` — Terms of Use (optional but recommended)
